# ZAISAKU agent instructions

Before any visual, world, interface or asset decision, read [the Art & Design Constitution](docs/ZAISAKU-ART-CONSTITUTION.md) and [canonical visual targets](docs/art-direction/canonical-references/README.md). These are mandatory, not optional inspiration. The constitution supersedes conflicting old guidance while preserving explicit creator-approved assets and decisions.

Mineral Analog: Zuisaku is an independent planet, not fantasy, Japan, steampunk or Earth. Vey, Oru and Sera are native material families. Use instrument-like architecture, believable roofs/doors/scale, native biological families and purposeful composition. Preserve Quiet Instrument, dynamic type, tap-to-walk and no mobile joystick. Never rasterise live values or replace approved assets without review.

Follow [production workflow](docs/ART-PRODUCTION-WORKFLOW.md) and [foundation priorities](docs/art-direction/FOUNDATION-PASS.md). Distinguish concepts, file validation, in-game validation and creator approval. Run existing checks and inspect actual desktop and mobile gameplay before approval. Never claim unrun tests or merge unapproved art into main.
